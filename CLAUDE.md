# Quartett Mediathek – working notes for agents

Read `docs/SPEC.md` first. Visual reference: `docs/mockup.html`.

## Conventions
- Code, comments, identifiers, file names, commit messages: English. UI strings: `app/src/main/res/values/strings.xml`
  (English) and `values-de/strings.xml` (German). Every new string goes into both files.
- Package root `net.wi7.quartettmediathek` (`shared`), `net.wi7.quartettmediathek.tv` (`app`).
- `shared/src/commonMain/.../repository/Repositories.kt` is the contract between data and UI. Change it only if
  really needed and keep both sides compiling.
- `shared` must stay free of Android APIs (it also targets the JVM; later Apple TV / Linux).
- Icons: only `res/drawable/ic_*` generated by `tools/icons/convert.py`. Never load fonts, icons or other assets
  at runtime from the internet.
- Keep functions small, prefer pure functions for logic (dedupe, parsing, mapping, seek) and unit test them in
  `shared/src/commonTest` (runs on the JVM).
- Network tests against live APIs are not part of the normal test run. Record JSON fixtures into
  `shared/src/jvmTest/resources/fixtures/` and test parsers against them with Ktor `MockEngine`.

## Build (this container)
```
export ANDROID_HOME=/home/user/android-sdk
./gradlew :shared:jvmTest            # fast logic tests
./gradlew :app:assembleDebug         # TV app
./gradlew :shared:jvmTest :app:assembleDebug :app:lintDebug
```
`local.properties` points to the SDK (not committed). In this container Maven Central is mirrored through
`~/.gradle/init.d/maven-mirror.gradle` (rate limits); do not add mirror URLs to the repository.
